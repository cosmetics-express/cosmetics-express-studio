COSMETICS EXPRESS STUDIO

נכנסים לסטודיו שלך.
בלי דומיין ובלי רכישת אחסון.

החבילה מכילה את המערכת ואת קובצי ההפעלה. היא פועלת במחשב שלך ושומרת בו את הקמפיינים והלידים. את החלון הזה אפשר לפתוח גם לפני התקנת המערכת — הוא מדריך בלבד.

  1. חלצו את קובץ ה־ZIP לתיקייה רגילה. אין להפעיל מתוך קובץ ה־ZIP.
  2. התקינו Node.js בגרסת 24 LTS, עם npm. אם כבר מותקנת גרסה 24, אין צורך להתקין שוב.
  3. Windows: פתחו את start-demo.cmd.
    Mac: פתחו את start-demo.command. אם הרשאות ההפעלה מונעות פתיחה, פתחו Terminal בתיקייה והריצו bash start-demo.command.
    אפשר גם לפתוח Terminal בתיקייה ולהריץ npm run demo בכל מערכת הפעלה.
  4. בהפעלה הראשונה הרכיבים יותקנו מהאינטרנט. המתינו להודעה ״הדמו מוכן לשימוש״. אין צורך בכרטיס אשראי, בשרת או במפתחות API.
  5. הדפדפן ייפתח אוטומטית. אם לא נפתח, היכנסו ל־http://localhost:3000/login באותו מחשב שבו הפעלתם את הקבצים.
  6. לחצו ״כניסה לסטודיו לדוגמה״. אפשר ליצור קמפיין, לערוך טקסט ומחיר, להוריד עיצוב ולבדוק דף נחיתה ולידים.
מה יש בדמו? חשבון לדוגמה, קמפיינים ולידים לדוגמה, עורך בעברית ומכסה של 30 קרדיטי הדגמה. יצירה משתמשת באיור לדוגמה ולא ב־AI אמיתי. אין חיוב ואין סליקה. דפי הנחיתה פועלים מקומית בלבד, ואינם מתפרסמים לאינטרנט.

סגירה והפעלה מחדש

השאירו את חלון ההפעלה פתוח בזמן השימוש. לסיום לחצו בו Ctrl+C. להפעלה נוספת פתחו שוב את אותו קובץ. המידע נשמר בתיקיית .data; אל תמחקו אותה אם רוצים לשמור את העבודה.

אם פורט 3000 תפוס

סגרו חלון קודם של הדמו, או פתחו Terminal בתיקיית המערכת והריצו:

npm run demo -- --port 3001

לאחר ההפעלה אפשר לגלוש ל־http://localhost:3001/login.

אם יש לך cPanel

cPanel הוא לוח ניהול. כדי להריץ את המערכת הזו צריך שבחבילת האחסון תהיה תמיכה ב־Node.js 24, בהרצה מתמשכת ובקבצים מקומיים שנשמרים. חפשו ״Setup Node.js App״ או ״Application Manager״ ובדקו אילו גרסאות קיימות. אם יש רק אחסון PHP/WordPress, העלאת ה־ZIP לבדה לא תפעיל את המערכת.

אפשר להשתמש בכתובת זמנית של חברת האחסון, אם היא מספקת כזו, בלי לקנות דומיין חדש. נדרשת התאמת הגדרות לפריסה; קובצי ההפעלה כאן מיועדים למחשב המקומי. הוראות כלליות ודרישות שירותי הייצור נמצאות ב־README.md.
